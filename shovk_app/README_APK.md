# Как получить APK

Я не могу собрать APK в своей среде: там нет Flutter, Android SDK и интернета. Поэтому в проект добавлена автоматическая сборка. Вам не нужно ничего устанавливать, нужен только аккаунт на github.com и компьютер (с телефона загружать файлы неудобно).

## Способ 1. Сборка на GitHub (бесплатно, 10–15 минут)

1. Зарегистрируйтесь на github.com и нажмите New repository. Назовите, например, `shovk`, выберите Private, создайте.
2. Распакуйте `shovk_app.zip`. На странице репозитория нажмите Add file → Upload files и перетащите всё содержимое папки `shovk_app`, включая папки `.github`, `lib`, `tools`. Нажмите Commit changes.
3. Если папка `.github` не загрузилась (скрытые папки иногда пропускаются): Add file → Create new file, в имени файла введите `.github/workflows/build-apk.yml` и вставьте туда текст из файла `build-apk.yml` (он лежит в корне проекта). Нажмите Commit.
4. Откройте вкладку Actions → Build APK → Run workflow. Сборка займёт 10–15 минут.
5. Когда рядом с запуском появится зелёная галочка, откройте его и внизу в разделе Artifacts скачайте `shovk-apk`. Внутри архива файл `app-release.apk`.
6. Отправьте APK на телефон (Telegram, почта, кабель) и откройте его. Android попросит разрешить установку из этого источника.

Если вместо галочки красный крест, откройте шаг, который упал, и пришлите мне текст ошибки: я не мог скомпилировать код, поэтому первые правки возможны.

Без настроек APK соберётся в демо-режиме (данные тестовые, бэкенд не нужен, картинки подгружаются из интернета). Чтобы подключить ваш сервер: Settings → Secrets and variables → Actions → вкладка Variables, добавьте `USE_MOCK=false`, `API_BASE=https://ваш-сервер`, `PUBLIC_HOST=ваш-домен`, затем запустите сборку заново.

## Способ 2. Попросить разработчика

Любому Flutter-разработчику это 15 минут: `flutter create`, скопировать `lib`, `pubspec.yaml` и выполнить `python3 tools/prepare_android.py`, затем `flutter build apk --release`.

## Важно

- APK подписан тестовым ключом: подходит для вашего телефона и тестов. Для Google Play нужен собственный ключ подписи.
- APK работает только на Android. Для iPhone нужен Mac, Xcode и аккаунт Apple Developer ($99 в год), это другая сборка.
- Push-уведомления и аналитика Firebase включаются отдельно (см. README.md, раздел про Firebase).
